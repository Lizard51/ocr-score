# Система оценки читаемости текста на изображении (OCR-подготовка)

Веб-приложение на Flask для анализа пригодности изображений к оптическому распознаванию символов (OCR).

## Описание проекта

Проект позволяет загрузить изображение с текстом и получить оценку его пригодности для OCR на основе:
- **Контрастности** — стандартное отклонение интенсивности пикселей
- **Резкости** — дисперсия лапласиана изображения
- **Итоговой оценки** — от 1 до 10

**Важно:** Проект НЕ выполняет распознавание текста, только оценивает качество изображения.

## Почему такая структура?

1. **Минимализм** — проект учебный, не требует сложной архитектуры
2. **Без Blueprint** — достаточно одного файла `app.py` для такого масштаба
3. **SQLite вместо PostgreSQL** — не требует установки СУБД, хранится в одном файле
4. **Прямые SQL-запросы** — ORM избыточна для простой таблицы с 7 полями
5. **OpenCV напрямую** — без дополнительных абстракций

## Как это работает

### 1. Контрастность
Вычисляется как стандартное отклонение интенсивности пикселей в градациях серого:
```python
contrast = np.std(gray)
```
- Типичные значения: 10–80
- Чем выше, тем лучше различим текст

### 2. Резкость
Вычисляется через дисперсию лапласиана:
```python
laplacian = cv2.Laplacian(gray, cv2.CV_64F)
sharpness = np.var(laplacian)
```
- Типичные значения: 50–1000+
- Высокие значения = чёткие края текста

### 3. Итоговая оценка
```python
score = 0.4 * contrast_normalized + 0.6 * sharpness_normalized
```
Резкость имеет больший вес (60%), так как размытый текст критичен для OCR.

## База данных

Таблица `analysis_results`:
| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| filename | TEXT | Исходное имя файла |
| image_path | TEXT | Путь к файлу на сервере |
| contrast | REAL | Значение контрастности |
| sharpness | REAL | Значение резкости |
| ocr_score | INTEGER | Оценка 1–10 |
| explanation | TEXT | Текстовое пояснение |
| created_at | TIMESTAMP | Дата и время анализа |
