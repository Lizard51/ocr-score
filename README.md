# OCR Score

Учебное Flask-приложение для оценки читаемости текста на изображениях перед OCR. Результат показывает, насколько на оценку влияют контрастность и резкость.

[![Лицензия MIT](https://img.shields.io/badge/license-MIT-427259)](LICENSE)

## Состояние проекта

Реализация находится в [ветке прототипа](https://github.com/Lizard51/ocr-score/tree/ocr-readiness-assessment-system-9be1b). В [PR #1](https://github.com/Lizard51/ocr-score/pull/1) можно посмотреть код и описание. Обработка изображений и история анализов пока находятся в рабочих ветках.

## Возможности прототипа

- Загрузка изображения через веб-форму.
- Измерение контрастности и резкости с OpenCV.
- Оценка от 1 до 10 и подсказки по улучшению изображения.
- Сохранение результатов в SQLite и просмотр истории.

Оценка относится к качеству изображения. OCR-движок в прототипе отсутствует.

## Код и запуск

Описание форматов, зависимостей и команд локального запуска находится в [README ветки прототипа](https://github.com/Lizard51/ocr-score/blob/ocr-readiness-assessment-system-9be1b/README.md). Для демонстрации используйте тестовое изображение.
